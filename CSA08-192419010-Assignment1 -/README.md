## Assignment Overview
This repository contains the complete implementation, analysis, test suites, and visual evidence for **Assignment 1: Village Milk Co-operative Payment Calculator**.

### Directory Structure & Files
* `assignment_report.md`: Complete handwritten-style markdown assignment submission report.
* `milkrate.py`: Primary Python module implementing milk payment rate calculations.
* `Task01_problem_analysis.py`: Problem inputs, outputs, constants, and validation specifications.
* `Task02_values_and_types.py`: Primitive data types, float precision issues, and Decimal comparison.
* `Task03_constants_and_variables.py`: Constants definition, dynamic typing, and tuple swapping mechanics.
* `Task04_expressions.py`: Operator precedence and rounding functions comparison (`round`, `int`, `math.floor`).
* `Task05_input_conversion.py`: Robust input validation using `try-except` blocks and f-string formatting.
* `Task06_functions.py`: Functional modularization of payment formulas.
* `Task08_algorithm_plan.py`: Algorithmic pseudocode and execution verification.
* `Task09_test_suite.py`: Automated assertion test suite for edge case validation.
* `Task10_performance_benchmark.py`: Execution time and memory benchmark for up to 150,000 farmers.
* `Task11_final_design_recommendation.py`: Design justification and JSON configuration evaluation.
* `Task12_day4_revised_calculator.py`: Adaptations for automatic milk analyser and seasonal bonus rates.
* `sample_input_data.csv`: Sample milk collection records.
* `flowchart_task8.png`: Visual flowchart diagram for Task 8.
* `evidences_log.txt`: Comprehensive log of all generated outputs and visual evidence.
* Screenshots (`task1_output.png` through `task12_output.png`): Visual terminal output evidence.
